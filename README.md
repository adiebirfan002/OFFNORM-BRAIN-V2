# OFFNORM BRAIN V2

The working brain for OFFNORM, a Malaysian running apparel brand. V2 starts from a study of four reference
brands and turns it into a narrative and a logo brief.

## Read in this order

1. [research/patterns.md](research/patterns.md): what the four brands share and where the gaps are
2. [brand/narrative.md](brand/narrative.md): proposed OFFNORM narrative
3. [brand/logo-brief.md](brand/logo-brief.md): proposed logo brief
4. [brand/identity/](brand/identity/README.md): proposed logo system, mock-ups and proposal page

## Brand studies

| Brand | File | Main lesson for OFFNORM |
|---|---|---|
| Satisfy | [research/satisfy.md](research/satisfy.md) | Cotton can be technical if it is engineered and named. Own a feeling |
| ACG | [research/acg.md](research/acg.md) | Three letters in a fixed container. The name is the promise. Be funny |
| FPA | [research/fpa.md](research/fpa.md) | Acronym that re-expands. Numbering and kit logic. Asian brand, own system |
| norda | [research/norda.md](research/norda.md) | One material truth. Number the products. Restraint |

Sources and what could not be verified: [research/sources.md](research/sources.md)

## Rules for this repo

- Anything marked proposal must not be used as if it were decided.
- In the research files, **[S]** means sourced, **[M]** means from memory and needs checking, **[R]** means opinion.
- Reference brands are for learning mechanics. Their marks, words and signature looks are not to be copied; each
  study ends with a "what not to copy" list.
