# Blender model: Sky tee + 3/4 tights (first pass, 2026-11-19)

Run: `/Applications/Blender.app/Contents/MacOS/Blender -b -P kit.py -- <repo> <outdir> front,three,closetight,flash 40`
Views: front, back, three, closetee, closetight, flash (flash last; it dims the lights).

- Tee: ported from tee3d.js geometry. Cotton-jersey shader (fine vertical wales), white panel on wearer's right sleeve, rib collar, symbol centre chest, wordmark on back.
- Tights: ribbed nylon shader, deep waistband with tab. Logo = OFFNORM wordmark, vertical, reflective silver (updated 2026-11-19 per founder). Flash view lights it up like retroreflective print.
- Fabric looks are procedural guesses from the Satisfy/UVU research, not measured swatches.
- Not yet: socks, cap, underarm mesh, seam lines, the other 35 colourways, a body form. The backdrop has a visible floor edge.
