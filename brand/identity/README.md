## The marks

| Mark | File | Use |
|---|---|---|
| Wordmark | `wordmark-*` | Neck label, header, packaging |
| Monogram OFN | `monogram-OFN-*` | Chest, cap, sock. The mark to register |
| Symbol, the Stray | `symbol-stray-*` | Avatar, vent grid, pattern |
| Badge | `badge-*` | Patches, stickers |
| Stacked OFF / NORM | `stacked-*` | Square spaces |
| Lockups | `lockup-horizontal-*`, `lockup-vertical-*` | Signage, hang tag |
| App icon | `app-icon-*` | Instagram, Strava, favicon |

## Rules

- Letters are drawn as geometry in `kit.py`. Never retype the logo in a font.
- Low bars: the F bar and the R waist sit below centre.
- Sewn labels, tabs and stickers sit 3° off level (Kuala Lumpur is at 3°N). The master logo stays straight.
- Colours: Tarmac #17181A, Cotton #F6F7F5, Monsoon #8C9496, Bandung #F4A6C0.
- Type: Archivo Expanded (headlines), Archivo (text), IBM Plex Mono (numbers and conditions).
- Use ™ until the trademark is registered; ® is shown for the final look only.

Rebuild: `python3 brand/identity/source/build.py`
